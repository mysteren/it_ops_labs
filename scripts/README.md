# Скрипты и утилиты

Этот раздел содержит вспомогательные скрипты для автоматизации задач.

## 📜 Доступные скрипты

| Скрипт | Описание | Статус |
|--------|----------|--------|
| `setup-env.sh` | Настройка окружения | 🔜 планируется |
| `docker-cleanup.sh` | Очистка Docker ресурсов | 🔜 планируется |
| `backup.sh` | Резервное копирование | 🔜 планируется |
| `lab-check.sh` | Проверка лабораторных | 🔜 планируется |

## 🔧 Использование

Скрипты должны быть исполняемыми:

```bash
chmod +x script-name.sh
./script-name.sh
```

## 📝 Требования к скриптам

- Использовать `set -euo pipefail`
- Проверять наличие зависимостей
- Добавлять комментарии
- Обрабатывать ошибки
