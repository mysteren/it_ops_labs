# Проекты и примеры

Этот раздел содержит примеры проектов для изучения ITOps.

## 📁 Структура проектов

### Node.js проекты
- **basic-servers/** — базовые примеры серверов (HTTP, WebSocket, REST API)
- **pm2/** — конфигурации PM2 process manager

### Python проекты
- Примеры сервисов на Python (опционально)

### Vendor
- Сторонние проекты для изучения
- Исходники конфигураций

## 🎯 Назначение

Проекты используются для:
1. Демонстрации работы сервисов
2. Тестирования конфигураций
3. Практики с Docker контейнеризацией
4. Изучения PM2 и управления процессами
