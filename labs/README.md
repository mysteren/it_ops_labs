# Практические лабораторные работы

Этот раздел содержит практические занятия по всем темам ITOps.

## 🔬 Структура лабораторных

Каждая лабораторная работа включает:
- **Цель** — что нужно изучить
- **Предварительные требования** — что нужно знать заранее
- **Инструкция** — пошаговое выполнение
- **Конфигурационные файлы** — примеры конфигов
- **Задание для самостоятельной работы**
- **Контрольные вопросы**

## 🎯 Формат лабораторных

Лабораторные работы могут быть выполнены:
- В Docker контейнерах (предпочтительно)
- На виртуальных машинах
- На локальной Linux системе
