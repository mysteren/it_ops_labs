# Карта знаний ITOps

## 🗺️ Обзор

Карта знаний связывает все темы репозитория в единую систему. Каждая тема имеет связи с другими, образуя сеть знаний.

## 📊 Тематические блоки

### 1. 🔰 Foundation (Основы)
- Структура Linux
- Текстовые редакторы
- Полезные утилиты
- Форматы конфигов

### 2. 🐘 Containerization (Контейнеризация)
- Docker основы
- Docker Compose
- Сети
- Практические лабы

### 3. 🌐 Web Infrastructure (Веб инфраструктура)
- Nginx настройка
- SSL/TLS сертификаты
- Certbot

### 4. 💾 Data Layer (Уровень данных)
- PostgreSQL
- MongoDB
- Redis

### 5. 🔧 Application Layer (Приложения)
- Node.js сервера
- PM2 process manager
- Python проекты

### 6. 🔒 Security (Безопасность)
- Основы инфобеза
- Firewall
- SSH Hardening

### 7. 🛠️ Tools (Инструменты)
- npm, nvm, fnm
- uv (Python)

## 🔗 Связи между темами

| Тема | Связана с | Тип связи |
|------|-----------|-----------|
| Docker | Nginx | Reverse Proxy |
| Docker | Базы данных | Контейнеризация БД |
| Nginx | SSL | HTTPS настройка |
| Node.js | PM2 | Запуск приложений |
| Linux Basics | Все темы | Фундамент |
| Security | Все темы | Кросс-тематическая |
