# Инструменты разработки

Этот раздел содержит руководства по инструментам управления пакетами и версиями.

## 📦 Менеджеры пакетов и версий

### Node.js экосистема
- **npm** — менеджер пакетов для Node.js
- **nvm** (Node Version Manager) — управление версиями Node.js
- **fnm** (Fast Node Manager) — быстрая альтернатива nvm

### Python экосистема
- **uv** — современный менеджер пакетов для Python (быстрый, на Rust)

## 📋 Содержание

| Инструмент | Описание | Статус |
|------------|----------|--------|
| [npm](./npm/) | Менеджер пакетов Node.js | 🔜 планируется |
| [nvm](./nvm/) | Управление версиями Node.js | 🔜 планируется |
| [fnm](./fnm/) | Быстрый менеджер версий Node.js | 🔜 планируется |
| [uv](./uv/) | Менеджер пакетов Python | 🔜 планируется |
