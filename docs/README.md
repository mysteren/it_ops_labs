# Документация ITOps Labs

Этот раздел содержит всю документацию проекта.

## 📚 Разделы документации

| Раздел | Описание |
|--------|----------|
| [Roadmap](./roadmap/) | Пошаговый план изучения тем от базовых к продвинутым |
| [Knowledge Map](./knowledge-map/) | Карта знаний, связывающая все темы в единую систему |
| [Wiki](./wiki/) | Справочные материалы по каждой теме |
| [Tools](./tools/) | Руководства по инструментам (npm, nvm, fnm, uv) |

## 🗺️ Как использовать документацию

1. **Начните с Roadmap** — определите свой текущий уровень и следующую тему для изучения
2. **Посмотрите Knowledge Map** — поймите связи между темами
3. **Изучайте Wiki** — получайте теоретические знания
4. **Переходите к лабораторным** — применяйте знания на практике
